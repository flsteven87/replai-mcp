# Replai

Set up and run AI customer support for your SaaS product from your AI assistant. Connect your Replai Workspace, choose an Agent, add product knowledge, test answers, and review a publication before it reaches customers. Read support conversations, review reply drafts, and hand conversations to your team. Replai uses your team's knowledge and rules, with a shared Inbox for human support. A Replai account and browser authorization are required; each connection reaches one Workspace. Website chat and LINE are supported channels. Preview runs may incur usage charges. Publishing, sending replies, and removing resources are separate actions with their own permissions.

[Connection guide](https://replai.tw/en/guide/connect-ai-agents) · [Privacy](https://replai.tw/en/privacy) · [Terms](https://replai.tw/en/terms) · [Support](https://replai.tw/en/guide/troubleshooting)

## Connect

Install the package in your assistant, then authenticate the Replai MCP connection in its browser flow. Sign in with Google, choose one Workspace and approve the permissions for your task. Ask: “Show my Replai Workspace and support Agents.”

The remote endpoint is https://api.replai.tw/mcp. No API key or local server is required. You can revoke the connection in Replai under Workspace settings → External apps.

## Use

Add product knowledge, test a draft, review before publication, and read or work support conversations. Changes that publish, send or remove resources require their respective permissions. Preview usage may incur charges; see [pricing](https://replai.tw/en/pricing).
